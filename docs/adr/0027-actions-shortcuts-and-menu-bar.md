# 0027. 操作は Action で表し、メニューの項目とショートカットが同じ Action を指す。メニューバーはウィンドウの専用の場所に置く

- 状態: 承認
- 日付: 2026-10-04

## 背景

メニューバーと、キーの組み合わせ(ショートカット)で操作を実行する仕組みを作る。
これまでのメニュー([ADR 0022](0022-popups-combo-box-menu-tooltip.md))の項目(MenuItem)は `shortcut_text` を表示するだけで、キーでは実行しなかった。決めること:

- ショートカットと、それで実行する処理の結びつけ方。
- ショートカットが効く範囲。
- Windows 流のニーモニック(「ファイル(&F)」と Alt+F)と、キーボードでのメニューバーの操作。
- メニューバーの置き方。

## 検討した選択肢

結びつけ方:

- 選択肢A: 操作を `Action`(text・shortcut・enabled・checkable・checked・on_trigger)で表し、メニューの項目(と将来のツールバー・ボタン)が同じ Action を指す。
- 選択肢B: MenuItem に shortcut を持たせ、メニューに無いショートカットは別のオブジェクトで登録する。
- 選択肢C: ウィンドウに `add_shortcut("Ctrl+S", handler)` で登録する。メニューの表示と別に管理するので、表示と動作がずれやすい。

範囲:

- 選択肢A: ウィンドウ全体と、ウィジェット単位(フォーカスがその中にあるときだけ)の両方。
- 選択肢B: ウィンドウ全体だけ。

メニューバーの置き方:

- 選択肢A: `window->menu_bar` に代入すると、ウィンドウの上端に置き、レイアウトの領域はその下になる。
- 選択肢B: 普通のウィジェットとして、利用者がレイアウトの一番上に入れる。

## 決定

**結びつけは選択肢A(Action)、範囲は選択肢A(ウィンドウとウィジェット)、置き方は選択肢A(専用の場所)を選ぶ。ニーモニックにも対応する。**

### Shortcut

- キーと修飾キーの組の値。`"Ctrl+Shift+S"` のような文字から暗黙に作れる(`action->shortcut = "Ctrl+S"`)。修飾キーは過不足なく一致したときだけ実行する。
- Mac は対象外なので、Ctrl を Command に読み替えることはしない。
- 修飾キーそのものを表す `Key::SHIFT`・`CONTROL`・`ALT`・`META` を加えた(Alt を単独で押して離したことを知るため)。

### Action

- `trigger()` は、enabled なら、checkable のときに checked を反転してから on_trigger を呼ぶ。
- **ショートカットが効くのは、メニューバーのメニュー(サブメニューを含む)に入れた Action と、ウィジェット(ウィンドウを含む)の `add_action` で加えた Action だけ。**
  右クリックのメニューに入れただけの Action のショートカットは、表示だけにする(入力欄の Ctrl+C のように、キーはウィジェットが自分で扱うことが多いため)。
- キーの順番: ①メニューバーのキーボードの操作(Alt・F10・Alt+ニーモニック) ②フォーカスのあるウィジェットから親へ key_down
  ③受け取られなければ、フォーカスのあるウィジェットから親へ、加えた Action のショートカット ④メニューバーの Action。
  **ウィジェットが受け取ったキーはショートカットより優先する**(入力欄の Ctrl+A は、ウィンドウの「すべて選択」より先)。
- 無効な Action は飛ばし、次の候補を探す。
- Action は入れたメニュー・ウィジェットを所有しない。Action を破棄すると、メニューの項目からもウィジェットからも外れる。

### Menu(ADR 0022 の変更)

- **項目は Action で表し、公開の MenuItem をやめた。** `add_item(text, handler)` は Action を作って返し(メニューが所有する)、
  `add_action(action)` は既にある Action を入れる(所有しない)。チェックできる Action にはチェックの印を出す。
- `title`(メニューバー・サブメニューの項目に出す名前)を加えた。
- 開いたメニューの中では、項目のニーモニックのキーで選ぶ(同じキーの項目が複数あれば、順に強調するだけ)。

### MenuBar

- `add_menu(title)`・`remove_menu`・`menus`。`window->menu_bar = bar` でウィンドウの子になり、上端に置く(前のものは破棄する)。
- マウス: 見出しを押すと開く。開いている間は、ポインタが乗った見出しのメニューに切り替える。
- キーボード: Alt+ニーモニックで開く。Alt を押して離す・F10 でメニューバーへ移り、←→ で選び、↓・Enter で開き、Esc でやめる。
  開いたメニューの中の ←→ は隣のメニューへ移り、Esc はメニューバーへ戻る。
- ニーモニックの下線は、Alt を押している間・メニューバーへ移っている間・キーボードで開いたメニューに出す(マウスで開いたときは出さない)。

## 影響

- メニューを開いている間は、キーはメニューへ送るので、ショートカットは効かない。
- ツールバー・ボタンに Action を付けること、ラベルのニーモニックでフォーカスを移すこと(「名前(&N)」で入力欄へ)は対象外(必要になったら追加する)。
- 記号のキー(Ctrl++ など)は Key に無いので、ショートカットにできない。
