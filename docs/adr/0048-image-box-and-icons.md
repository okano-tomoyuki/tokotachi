# 0048. 画像を表示する部品 ImageBox と、ラベル・ボタン・メニューの画像を加え、拡大・縮小を滑らかにする

- 状態: 承認
- 日付: 2026-10-11

## 背景

画像(`Image`)は、ツールバーのボタン(Action の icon)と、一覧・木の項目のアイコンにしか出せなかった。
画像をそのまま表示する部品が無く、ラベル・ボタンにアイコンを付けることも、メニューの項目に画像を出すこともできなかった
([ADR 0027](0027-actions-shortcuts-and-menu-bar.md) では、メニューの画像を対象外としていた)。
また `Canvas::draw_image` は大きさを変えて描くとき plutovg の「最も近い画素」を取るだけなので、拡大するとぎざぎざになり、
縮小(倍率 1 の画面で 32 ピクセルのアイコンを 16 で描くなど)では細い線が欠けていた。

## 検討した選択肢

- 画像の部品
  - 選択肢A: Label に画像を足し、文字の代わりに大きな画像も出せるようにする。
  - 選択肢B: 画像だけの部品 `ImageBox` を別に作り、Label・Button には文字の前の小さな画像(アイコン)だけを足す。
- 拡大・縮小
  - 選択肢C: plutovg の描き方のまま(最も近い画素)。
  - 選択肢D: 写す先の大きさに先に滑らかに写した画像を作って覚えておき、それを等倍で描く。

## 決定

選択肢B と D を採る。

- `ImageBox`(`widgets/image_box.hpp`): `image` と `fit`(`ImageFit`: `NONE` 元の大きさ・`CONTAIN` 収める・`COVER` 覆う・`STRETCH`
  伸ばす。既定 `NONE`)。どれも中ほどに置き、はみ出した部分は描かない。画像の 1 ピクセルを論理座標の 1 とし、望む大きさは画像の大きさ。
- `Label`・`Button` の `icon` と `icon_size`(既定 16): 文字の前(Label は段落の向きの始め)に画像を出す。Button は `text` が空なら
  画像だけの正方形に近いボタンになる。画像と文字の間は 6。
- メニュー: Action の `icon` を文字の前の列に出す。checkable でチェックしているなら、画像を枠で囲む(画像が無ければ従来のチェックの印)。
- 無効なとき、画像は不透明度 0.4 で描く(ツールバーと同じ)。
- `Canvas::draw_image` は、ピクセルにそろえた描き先の大きさが画像と違えば、縮めるときは面積の平均、広げるときは線形補間で写した画像を
  作り、Image の中身に最近使った大きさ 4 つまで覚えておく(ロックで守り、別のスレッドの描画からも使える)。回転・斜めの変換のときは従来どおり。
- デザイナーは、画像のプロパティ(定義ファイルからの相対パスを書き、生成するコードに埋め込む)をそのまま使う。`ImageBox` はパレットの「表示」に置く。

## 影響

- アイコンは 16(倍率 2 の画面のために 32 ピクセルで用意するとよい)を基本とし、ツールバー・一覧・メニュー・ラベル・ボタンで同じ画像を使える。
- 大きさを変えた画像を描くたびに写すのではなく覚えておくので、アニメーションで大きさを毎回変えると、そのたびに写し直す
  (大きさ 4 つを超えると古いものから捨てる)。
- 画像の位置(文字の上・下に置くなど)・SVG の画像・画像の色をテーマに合わせて変えることは対象外(必要になったら追加する)。
