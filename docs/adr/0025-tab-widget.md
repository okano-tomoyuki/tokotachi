# 0025. TabWidget はタブを Tab オブジェクトで表し、ページを子として持ち、見出しがはみ出したら横にスクロールする

- 状態: 承認
- 日付: 2026-10-04

## 背景

複数のページを見出しで切り替える部品(タブ)を作る。決めること:

- 1 つのタブの見出し・有効かどうか・ページを、どう表すか。
- ページの持ち主と、ページが破棄された・別の親へ移されたときの扱い。
- 見出しが幅に収まらないときの扱い。
- 見出しの位置(上・下・左・右)。
- キーでの操作。

## 検討した選択肢

タブの表し方:

- 選択肢A: タブを `Tab` オブジェクトにし、`title`・`enabled` などを Property で持つ。結びつけ([ADR 0016](0016-property-binding.md))もできる。
- 選択肢B: 番号で指定する関数(Qt の `setTabText(index, ...)`)。状態を Property だけで持つ方針([ADR 0013](0013-api-style-properties-and-handlers.md))に合わない。

見出しがはみ出したとき:

- 選択肢A: 左右にスクロールする(◀▶ のボタンとホイール)。
- 選択肢B: 複数の段に折り返す。段の並びが選ぶたびに変わり、分かりにくい。
- 選択肢C: 見出しを縮めて省略する。見出しが読めなくなる。

## 決定

**タブは選択肢A(Tab オブジェクト)、はみ出しは選択肢A(左右にスクロール)を選ぶ。見出しは上だけに置く。**

### Tab

- `title`・`enabled`・読み取り専用の `page`。TabWidget が作って所有し、利用者は作らない・破棄しない。
- `enabled = false` のタブは、押しても・キーでも選べない。`current_index` への代入では選べる(プログラムの判断を優先する)。

### TabWidget

- `add_tab(page, title)`・`insert_tab(index, page, title)` はページを TabWidget の子にし、Tab を返す。
  同じページを 2 度加えると既存の Tab を返す。子にできないもの(ウィンドウ・祖先)は加えず nullptr を返す。
- 最初のタブを加えると、それを選ぶ。選んでいるタブより前に加えたときは、同じタブを選んだまま番号をずらす。
- `remove_tab(tab)` はタブを除き、ページを返す。ページは親が無くなり、見える状態に戻り、呼んだ側が持つ。
- **ページを破棄した・別の親へ移したときは、そのタブも消える。** このために Widget に、子が外れたことを知らせる
  protected の仮想関数 `child_removed(child)` を加えた。
- 選んでいたタブが消えたら、同じ位置(無ければ 1 つ前)のタブを選ぶ。タブが無くなると `current_index` は -1。
- `tabs`(読み取り専用)・`current_index`・`current_tab`(読み取り専用)・`on_change`。
  `on_change` は利用者の操作・代入・タブの追加と削除のどれで `current_index` が変わっても呼ぶ。
- ページは見出しの下の全体に置き、選んでいるページだけを見せる。大きさの希望は、どのページを選んでも収まる大きさ。
  最小の幅は見出しで決めない(スクロールできるので)。

### 見出しとスクロール

- 見出しの幅は文字の幅と左右の余白(最小 48dp)。選んでいる見出しはアクセントの色の文字と下線。
- 収まらないときは右端に ◀▶ を出し、見出しの並びの上のホイールでも横にスクロールする。
  選んだ見出しは見える位置までスクロールする。

### キーとフォーカス

- 見出しを押すと TabWidget がフォーカスを得る(`FocusPolicy::CLICK`。Tab キーの巡回には入れない)。
  フォーカスがあるときは ←→(端で止まる)・Home・End で選ぶ。
- **Ctrl+Tab・Ctrl+Shift+Tab・Ctrl+Page Up/Down は、ページの中のどこにフォーカスがあっても届き、巡回する。**
  子が受け取らなかったキーは親へ送られる仕組みを使う。無効なタブは飛ばす。
- 隠すページの中にフォーカスがあったときは、TabWidget へフォーカスを移す。続けて Ctrl+Tab で切り替えられるように。

## 影響

- 見出しを下・左・右に置くこと、見出しのアイコン・閉じるボタン・ドラッグでの並べ替えは対象外(必要になったら追加する)。
- `child_removed` は他の入れ物の部品(分割ウィンドウなど)でも使える。
