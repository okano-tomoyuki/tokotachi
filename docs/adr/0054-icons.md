# 0054. よく使うアイコンを Lucide の線画としてライブラリに組み込み、部品の文字の色で塗る

- 状態: 承認
- 日付: 2026-10-12

## 背景

開く・保存・コピーのような定番のアイコンも、利用者が画像のファイルを用意するしかなかった。集めたアイコンは見た目が揃わず、
ダークのテーマ・倍率 2 の画面のために、色・大きさ違いの画像も要る。デザイナーは画像を生成するコードに埋め込むので(docs/adr/0053)、
同じアイコンをウィンドウごとに埋め込むことにもなる。

## 検討した選択肢

- 出どころ: 既存のアイコンセット(Lucide・Tabler・Material Symbols)/ 自分たちで描く。
- 持ち方: ビットマップ(PNG)/ 線画のパス。
- 置き場所: デザイナーが埋め込む / ライブラリに組み込む。
- 色: 作るときに決める / 描くときに部品の文字の色で塗る。
- API: Image の一種(`Image::icon`)/ 部品ごとに別のプロパティ。

## 決定

Lucide(ISC。一部は Feather の MIT)の線画を、ライブラリにパスとして組み込む。Image の一種にし、描くときに部品の文字の色で塗る。

- **データ**: [tools/icons/generate.mjs](../../tools/icons/generate.mjs) が lucide-static(版を固定。今は 1.48.0)の `icon-nodes.json` を読み、
  path・rect・circle・line を、移動・直線・3 次ベジェ・閉じるの並び(24 × 24 の格子)にして `src/graphics/icon_data.cpp` に書く
  (弧・2 次ベジェは 3 次ベジェにする)。実行するときに SVG は読まず、Canvas の Path で描く(描画の裏側によらない)。
  列挙型 `Icon`(`include/tokotachi/graphics/icon.hpp`)も同じツールが書く。名前は Lucide の正式な名前を大文字にし、`-` を `_` にしたもの
  (`folder-open` → `FOLDER_OPEN`。別名(`filter`・`circle-help` 等)は使わない)。
- **数**: 定番の 71 個(ファイル・編集・移動・表示・状態・再生・その他)。必要になったら分類の終わりに足す(列挙の値は並びの順)。
- **API**: `Image::icon(Icon)`・`Image::icon(Icon, Color)`(色を決める)・`Image::is_icon()`。Image なので、ラベル・ボタン・Action
  (メニュー・ツールバー)・一覧の項目・ImageBox など、画像を受け付ける所すべてで使える。大きさは 24 × 24 として扱い、24 × 24 に描いた
  画像も持つ(画素を読む・Bitmap に写すとき)。
- **描き方**: `Canvas::draw_image(image, dst, tint, opacity)` を加え、アイコンは dst の大きさに合わせて線(太さは格子の 2。端と角は丸い)を
  tint で引く(色を決めたアイコンはその色)。ほかの画像は今まで通り。tint を渡さない `draw_image` では黒で塗る。
- **部品**: ボタン・ラベル・ImageBox・メニュー・ツールバー・一覧は、文字の色を tint に渡す。無効のときは無効の文字の色で塗り、
  画像のように薄くはしない(文字と同じ見え方にする)。強調したボタン・メニューの選んだ行は、その文字の色になる。
- ライセンスは THIRD_PARTY_LICENSES.txt に加える(ISC と、Feather 由来のアイコンの一覧と MIT)。

## 影響

- ライブラリはアイコンのデータの分(約 28 KB のソース)大きくなる。
- 小さく描くと線は細くなる(16dp で約 1.3dp)。Lucide の既定(大きさに比例)に合わせた。

## 追記: デザイナー(2026-10-12)

- 画像のプロパティに `"icon:<名前>"`(列挙の名前を小文字にしたもの。`icon:folder_open`)と書く。ファイルではないので、
  画像の参照(存在の検査・埋め込み)に入れない。生成するコードは `tokotachi::Image::icon(tokotachi::Icon::FOLDER_OPEN)`。
- 一覧(`designer/packages/core/src/dsl/icons.json`。名前・Lucide の名前・分類・SVG のパス)も tools/icons/generate.mjs が書く。
  ライブラリと同じ線画なので、インスペクタの見本とキャンバス・実行した画面が一致する。
- インスペクタの画像の欄の ☆ で、分類ごとに並べたアイコンから選ぶ(名前で絞り込める)。
- キャンバス(WebAssembly)には、名前を列挙の値(`icon:3`)にして渡す。
