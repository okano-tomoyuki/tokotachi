# 0044. デザイナーの自作部品: 利用者が C++ で書いた部品のヘッダを読み、パレットに出して置く

- 状態: 承認
- 日付: 2026-10-11

## 背景

利用者は `tokotachi::Widget`・`PaintBox`・`ProgressBar` などから派生したクラス(`paint` を上書きしたゲージなど)を C++ で書く。
デザイナー([ADR 0039](0039-designer.md))のパレットはライブラリのカタログ([catalog.md](../designer/catalog.md))の部品だけなので、
自作部品は定義ファイルに置けず、コードで足すしかない。部品ファイル([ADR 0043](0043-designer-component-files.md))は部品の組み合わせを
使い回すもので、振る舞い・描画を持つ部品には使えない。

決めること:

- 自作部品のクラスの情報(基底クラス・プロパティ・ハンドラ)をどこから得るか。
- キャンバスでどう描くか(WebAssembly の Tokotachi に利用者のコードは入らない)。

## 検討した選択肢

情報の出どころ:

- 選択肢A: 自作部品のヘッダをプロジェクトファイルに登録し、拡張がヘッダを簡易に読む(`Property<T> name;` と `///` の説明)。
- 選択肢B: プロジェクトファイルに、クラス・ヘッダ・基底クラス・プロパティ・ハンドラを JSON で書く。ヘッダと二重に書くことになる。
- 選択肢C: ライブラリのカタログと同じく Doxygen で取り出す。正確だが、利用者の環境に Doxygen が要り、遅い。

描き方:

- 基底クラスで描く: Button の派生なら Button として作り、基底のプロパティを設定する。Widget・PaintBox の派生は仮の絵(枠とクラスの名前)にする。
- すべて仮の絵にする。

## 決定

**情報は選択肢A、描き方は基底クラスで描く。** ヘッダを直せばデザイナーにも効き、利用者の手間が少ないため。

- プロジェクトファイル: `"custom_widgets": ["src/widgets/gauge.hpp"]`(プロジェクトのフォルダからの相対パス)。自作部品はプロジェクトに属するウィンドウでだけ使える。
- ヘッダの読み方(core。文字列を受け取るだけ):
  - `class Gauge : public tokotachi::PaintBox` の形のクラス。基底はカタログの部品か、同じく登録した自作部品。名前空間(`namespace app {`)を読み、
    生成するコードでは `app::Gauge` と書く。
  - public の `Property<T> name;`(`tokotachi::` は省いてもよい)。T がカタログの型(bool・int・float・double・std::string・
    列挙型・値の型・`std::vector<std::string>`・部品へのポインタ)ならプロパティ、ハンドラの型(`NotifyHandler` 等)ならハンドラにする。
    読めない型は飛ばす。直前の `///` を説明にし、`{3}`・`= 3` のような文字の既定値があれば既定値にする。
  - 基底のプロパティ・ハンドラを受け継ぐ。子(`layout`・`children`)は持てない。
- カタログ: 自作部品はカタログ(`findClass`)に足して扱う。検証・インスペクタ・コード生成はライブラリの部品と同じ。パレットには「自作部品」の分類で出す。
- 生成するコード: `gauge_1 = new app::Gauge(this);`、メンバの型は `app::Gauge*`。ヘッダから自作部品のヘッダを include する(ヘッダのフォルダからの相対パス)。
- キャンバス: 基底のカタログの部品(派生をたどって最初に当たるもの)として作り、自作のプロパティは設定しない。基底が Widget・PaintBox なら、
  デザイナーが枠とクラスの名前を重ねて描く。`minimum_size` を書いていなければ、仮の大きさ(120×80)を与える。
- 読めないヘッダ・基底が分からないクラスは、プロジェクトファイルの問題として出す。

## 影響

- 自作部品の描画はキャンバスに出ない(基底の見た目か仮の絵)。大きさと位置は正しく出る。
- ヘッダの書き方によっては読めないプロパティがある(マクロ・typedef した型・複数行の宣言)。読めないものはデザイナーで設定できないだけで、コードは通常どおり動く。
- プロジェクトに属さないウィンドウでは自作部品を使えない。
