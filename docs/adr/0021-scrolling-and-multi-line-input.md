# 0021. スクロールはホイールのイベント・ScrollBar・ScrollArea で扱い、複数行の入力欄は LineEdit と共通の基底から作る

- 状態: 承認
- 日付: 2026-10-04

## 背景

[ADR 0019](0019-line-breaking-and-text-navigation.md) で複数行のレイアウトを入れたので、複数行の入力欄(TextEdit)を作る。
それには縦のスクロールが要り、画面に収まらない中身を見せる一般のスクロール領域(ScrollArea)も要る。
マウスのホイールのイベントは、まだ扱っていなかった。

## 決定

### ホイール

- `WheelEvent`(位置、回した量 `delta`、修飾キー)と、`Widget::mouse_wheel`(仮想関数)・`on_mouse_wheel`(ハンドラ)を加える。
  `delta` は目盛りの数で、y が正なら奥へ回した(上へスクロールする)。OS の「逆向きのスクロール」の設定は反映済みにする。
- ポインタの下の最も深いウィジェットへ送り、受け取らなければ(`accepted == false`)親へ送る。スクロールできないウィジェット
  (端まで来た・中身が収まっている)は受け取らず、外側のスクロール領域が動く。

### ScrollBar

- `value`(0 から `maximum`)・`maximum`(動かせる量)・`page_step`(見えている長さ。つまみの大きさ)・`single_step`(ホイールの 1 目盛り)。
  範囲の外の値は丸め、`maximum` を小さくすると `value` も丸める。`on_change` は値が変わったときに呼ぶ。
- つまみのドラッグ、溝のクリック(1 ページ分)、ホイールで動かす。フォーカスは取らない。

### ScrollArea

- `content` に中身のウィジェットを入れる(内部の「見えている範囲」のウィジェットの子に付け替える。前の中身は破棄する)。
- 中身の大きさは中身の `preferred_size`。`fit_width`(既定 true)なら幅は見えている幅に合わせ、縦だけスクロールする。
  収まらない向きにだけスクロールバーを出す(片方を出すと見えている範囲が狭まるので、もう片方の要否を確かめ直す)。
- `scroll_position`(プロパティ)と `scroll_to_visible(rect)`。
- ScrollArea は子の配置を自分で決める。そのため `Widget::arrange_children()`(仮想関数。配置のやり直しの印が付いたとき、描画の前に呼ぶ。
  既定はレイアウトに任せる)を加え、ScrollArea が上書きする。中身の望む大きさが変わると、[ADR 0017](0017-layout.md) の仕組みで
  ScrollArea まで印が付き、配置し直す。ScrollArea にレイアウトを付けてはいけない(付けても使わない)。

### 複数行の入力欄(TextEdit)と共通の基底(TextInputBase)

- LineEdit の編集・選択・クリップボード・IME の変換中の文字列・キャレットの点滅・スクロール・変更の通知を **`TextInputBase`** に移し、
  LineEdit と TextEdit をその派生クラスにする(ButtonBase と同じ考え方)。派生クラスは、文字を描く矩形(`text_area`)・
  折り返しの幅(`wrap_width`)・Enter(`submit`)・枠の描画を決める。既存の LineEdit のテストが、作り直しで動作が変わらないことを確かめた。
- 複数行では、上下の矢印(キャレットの横の位置を保つ)、Page Up・Down(見えている行の数だけ)、Home・End(行の始め・終わり。Ctrl で全体)、
  Enter で改行を入れる。入れる文字列は、改行を `\n` にそろえ(`\r\n`・`\r`)、タブは空白にし、その他の制御文字を除く。
- スクロールの量は、キャレットが動いた・テキストが変わった・大きさが変わったときにだけ、キャレットが見えるように直す
  (描画のたびには直さない。ホイール・スクロールバーで動かした位置を保つため)。
- TextEdit は `word_wrap`(既定 true)で幅に合わせて折り返し、右にスクロールバーを出す。**スクロールバーの幅は常に空けておく**
  (出し入れで折り返しの幅が変わり、行が組み替わり続けるのを避けるため)。
- 折り返すときの行のそろえ方は、最も広い行の幅ではなく折り返しの幅に対して行う(右から左の段落が入力欄の右端にそろうように)。

## 影響

- TextEdit は自分の中でスクロールする。ScrollArea の中に TextEdit を入れると、TextEdit が端まで来たときだけ外側がスクロールする。
- 横のスクロールバーは、TextEdit では出さない(`word_wrap` を false にしたときは、キャレットを追って横にスクロールするだけ)。
- 慣性のスクロールや、なめらかなスクロールの動き(アニメーション)は対象外。
