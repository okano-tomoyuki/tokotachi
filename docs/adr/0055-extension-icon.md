# 0055. デザイナーの拡張のアイコンを、画面の部品で組んだ「常」にする

- 状態: 承認
- 日付: 2026-10-12

## 背景

VS Code の拡張(デザイナー)には、マーケットプレース・拡張の一覧に出すアイコンが無く、アクティビティバーのアイコンは画面の形の仮のものだった。
アイコンは、目を引き、GUI を組む道具だとわかり、名前(国之常立神の「常立」)の由来にもつながるものにしたい。

## 検討した選択肢

- 画面・鳥居・積み上げ・障子・紋・「常」の印(第 1 回の a〜f)。
- 日の出の窓・積み木・T の柱・設計図・窓の富士・部品を落とす(第 2 回の g〜l)。T の柱(窓の題の帯と、選んでいる柱)が良かった。
- T の代わりに「常」を画面の部品で組む案(m1〜m11)。選ぶ部品(柱・口)、地の色(赤・青・生成り)、ドラッグの表し方(その場でつかむ・持ち上げる)。

## 決定

「常」を画面の部品で組み、巾の中心の柱を選んでドラッグしている絵にする(m10)。

- 地は青のグラデーション(#2563EB → #1E2A5A)。⺌ は窓の 3 色の丸(赤・黄・緑)、冖・口・巾は白。
- 巾の中心の柱は強調の色(黄)で、影で浮かせ、四隅に選択の持ち手、左右に動かす向きの矢印、上にカーソルを置く。
  字の形は崩さない(持ち上げて動かす案は、字が読みにくくなった)。
- 元の絵は `designer/packages/extension/images/icon.svg`。マーケットプレースに出す `icon.png`(256 × 256、角の外は透明)は、
  これをブラウザで描いて作る。アクティビティバーの `activitybar.svg` は、同じ形を `currentColor` の線で描く(24 × 24)。
- 候補の画像(`images/drafts/`)はリポジトリにも拡張のパッケージにも入れない(.vscodeignore は使う 2 つの画像だけを含める)。

## 影響

- 16 px では細部は見えないが、青の地・3 色の丸・白い字の形で見分けられる。
