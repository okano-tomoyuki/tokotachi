# 0049. 見出しの付いた枠 GroupBox・部品のニーモニックと、値の部品・分割の細かな機能を加える

- 状態: 承認
- 日付: 2026-10-11

## 背景

フォームを作るときによく使う機能のうち、いくつかが欠けていた。

- 関係する部品を見出しの付いた枠でまとめる部品が無い。
- メニューにはニーモニック(「ファイル(&F)」と Alt+F)があるが([ADR 0027](0027-actions-shortcuts-and-menu-bar.md))、ラベル・ボタンには無く、
  キーボードで入力欄へ素早く移れない。
- ProgressBar は全体の量が分からない処理(待ち時間が読めない通信など)を表せない。SpinBox は単位を、Slider は目盛りを出せない
  ([ADR 0024](0024-value-widgets.md))。
- Splitter のたたんだ区画は境目をドラッグしないと戻せず、キーボードでは操作できない([ADR 0031](0031-splitter.md))。

## 検討した選択肢

ラベルのニーモニックで移る先の決め方:

- 選択肢A: Windows の流儀。ラベル・ボタンの text の「&」は常にニーモニックとして扱い(「&」を出すには「&&」)、ラベルはタブの順で
  次の部品へ移す。別の部品へ移すときは buddy で指定する。
- 選択肢B: Qt の流儀。ラベルに buddy を指定したときだけ「&」を解釈する。デザイナーで、ほかの部品を選ぶプロパティ(部品への参照)の
  仕組みを新しく作る必要がある。

## 決定

選択肢A を採る。

- **ニーモニック**: `Widget` に `mnemonic_key`・`mnemonic_activated`(仮想関数)を加える。ウィンドウは、Alt+キー(Ctrl・Shift などを
  一緒に押していないとき)を、メニューバーの次に、表示されていて有効な部品のうちそのキーを持つものへ知らせる。同じキーの部品が複数あれば、
  フォーカスのある部品の次のものへ順に移る。Alt を押している間は、ウィンドウ全体でニーモニックの下線を出す(`mnemonic_cues`)。
  - `Label`: text の「&」を解釈し、`buddy`(無ければタブの順でラベルの次の部品)へフォーカスを移す。`buddy` は部品への参照で、
    デザイナーでは設定しない(デザイナーでは並べた順で決まる)。
  - `Button`・`CheckBox`・`RadioButton`: text の「&」を解釈し、フォーカスを得て押したことにする。
  - `GroupBox`: title の「&」を解釈し、中の最初の部品へフォーカスを移す。
  - 部品から使えるよう、`focus_next_after`(タブの順で自分の後ろ)・`focus_first_within`(自分か子孫の最初)を公開する。
- **GroupBox**(`widgets/group_box.hpp`): `title` と、枠と見出しの内側(余白 12)の `content_rect`。付けたレイアウトは `content_rect` の中に
  並べる。見出しは枠の上の辺に重ね、見出しの所だけ線を切る。デザイナーでは入れ物(子を持てる)としてパレットに出す。
- **ProgressBar の `indeterminate`**: 棒の 3 割が 1.5 秒で左の外から右の外へ動き続ける。表示されている間だけタイマーで動かし、
  隠れたら止める(また描くときに動かし始める)。動き始めの位置は棒の左寄りで、最初に描いたときにも見える(デザイナーのキャンバスでも見える)。
- **SpinBox の `prefix`・`suffix`**: 数値の前・後ろに出す文字。打ち込むときは付けても付けなくてもよい(周りの空白は問わない)。
- **Slider の `tick_interval`**: 0 より大きければ、minimum からその間隔ごとと maximum に、溝の下(縦なら右)へ目盛りを出し、その分だけ望む太さを
  増やす。目盛りの間が 4 より詰まるなら出さない。
- **Splitter**: 境目のダブルクリックで、隣のたたんだ区画を戻す(どちらもたたんでいなければ stretch の小さい方、同じなら前をたたむ)。
  たたむときは大きさを覚えておき、戻すときにその大きさ(最小・望む大きさ以上)で隣の区画からもらう。`SplitterPane::collapsed` に
  代入してもたたむ・戻すことができる(`on_change` は利用者の操作のときだけ呼ぶ)。境目を押した後は、矢印キーで 10 ずつ動かし、
  Enter でダブルクリックと同じことをする。Splitter は境目を押したときだけフォーカスを得る(区画の中を押してもフォーカスを奪わない)。

## 影響

- 既存のラベル・ボタンの text に「&」があると、表示が変わる(「&」を出すには「&&」と書く)。
- タブの順は部品を作った順なので、入力欄をラベルより先に作ると、ラベルの「次の部品」は入力欄にならない。そのときは buddy を指定する
  (デザイナーで作る部品は並べた順に作るので、指定しなくてよい)。
- ニーモニックの下線は Alt を押している間だけ出る(メニューの開き方と同じ。常に出す設定は対象外)。
- タブの見出し・ツールバーのボタンのニーモニック、Splitter の境目へのタブでのフォーカス、Slider の目盛りの位置(上・両側)の指定は
  対象外(必要になったら追加する)。
