# 0030. ツールバーは Action をボタンとして並べ、ステータスバーとともにウィンドウの専用の場所に置く

- 状態: 承認
- 日付: 2026-10-04

## 背景

よく使う操作のボタンを並べるツールバーと、状態や知らせを出すステータスバーを作る。決めること:

- ボタンの見た目(画像・文字)。
- 幅に収まらないときの扱い。
- ステータスバーに用意するもの。
- 置き方と、ツールバーの Action のショートカット。

## 検討した選択肢

ボタンの既定の見た目:

- 選択肢A: 画像だけ(画像が無ければ文字)。文字はツールチップに出す。
- 選択肢B: 画像の右に文字。
- 選択肢C: 画像の下に文字。

はみ出したとき:

- 選択肢A: 収まらない項目を隠し、右端の » のメニューから選べるようにする。
- 選択肢B: 次の行へ折り返す。
- 選択肢C: 切るだけ。

## 決定

**見た目は選択肢A(`button_style` で B・C に切り替えられる)、はみ出しは選択肢A を選ぶ。**
ステータスバーには、普段の文字と一時的な知らせ、右側の部品を用意する。

### ToolBar

- ボタンは Widget の `add_action(action)` で加える。Widget に、Action が加わった・外れた・表示が変わったことを知らせる
  protected の仮想関数(`action_added`・`action_removed`・`action_changed`)を加え、ToolBar はそれでボタンを作り・消し・描き直す。
  Action を破棄すれば、ボタンも消える。メニューと同じ Action を入れれば、無効にしたときに両方が無効になる。
- `add_item(text, handler)`(Action を作って所有する)・`add_separator()`・`add_widget(widget)`(任意の部品)。
- Action に `icon`(画像)と `tooltip` を加えた。ツールチップが空なら、文字とショートカットから作る。
  ボタンの文字はメニュー向けの表記(末尾の「...」・「(&S)」の形のニーモニック)を省く。
- チェックできる Action のボタンは、チェックしている間は押し込んだ見た目にする。ボタンはフォーカスを受けない。
- 収まらない項目は隠し(add_widget の部品は visible を false にする)、» のメニューに隠した Action を並べる。

### StatusBar

- `text`(普段の文字。控えめな色)、`show_message(文字, ミリ秒)`(一時的な知らせ。0 なら `clear_message` まで)、読み取り専用の `message`。
- `add_widget(widget)` で右側に部品を並べる(加えた順に左から。間に区切りの線)。文字は部品の左までで切る。

### Window

- `menu_bar` と同じく `tool_bar`・`status_bar` を代入すると子になり、前のものは破棄する。上端にメニューバー・ツールバー、
  下端にステータスバーを置き、レイアウトにはその間の領域を渡す。
- **ツールバーの Action のショートカットは、ウィンドウ全体で効く**(フォーカスのあるウィジェット側の Action の後、メニューバーの前に探す)。

## 影響

- ツールバーは 1 つだけ・上だけ。複数のツールバー、移動・ドッキング、縦のツールバーは対象外。
- メニューの項目には Action の画像を出さない(必要になったら追加する)。
- ステータスバーの右下のつまみ(サイズグリップ)・メニューの項目の説明を出す機能は対象外。
