# 0046. 一覧・木に、項目ごとの文字の色とフォント・文字での検索・その場での編集を加える

- 状態: 承認
- 日付: 2026-10-11

## 背景

[ADR 0026](0026-item-model-and-views.md) では、項目ごとの文字の色・フォント、文字での検索、セルの編集を対象外にした。
エラーの行を赤くする・見出しの項目を太くする、ファイルの一覧で名前を変える、といったよくある使い方ができない。
フォントの太字・斜体は [ADR 0045](0045-font-bold-and-italic.md) で加えた。

## 検討した選択肢

編集の欄:

- 選択肢A: ビューが LineEdit を 1 つ持ち、編集するセルの上に置く。確定はモデルの `set_text` に知らせる。
- 選択肢B: 行ごとにウィジェットを置く(ADR 0026 の選択肢B)。大量の行で重く、見えている行だけを描くことと合わない。

文字での検索:

- 選択肢A: キーの文字(ASCII)で探す。IME を使わない。
- 選択肢B: 文字の入力(IME を含む)で探す。日本語でも探せるが、ビューにフォーカスがあるときに IME が有効になり、Enter・矢印のキーと干渉する。

## 決定

**編集の欄は選択肢A、文字での検索は選択肢A。**

- 文字の色とフォント: `ItemModel` に `text_color(index, column)`(既定は `ColorRole::TEXT`)と `font(index, column)`(既定は `Font()`)を加え、
  `Item` に `text_color`・`font` のプロパティを加える(すべての列)。フォーカスのあるビューで選んでいる行・無効な項目はビューの色で描く
  (選択の色の上で読めるように)。行の高さは既定のフォントで決まるので、大きいフォントははみ出た分が切れる。
- 文字での検索: 修飾キー無しで文字のキーを押すと、1 列目の文字がそれで始まる項目へ動く(ASCII の英字の大文字・小文字は区別しない)。
  1 秒以内に続けて押すと前方一致で探し、同じ文字を続けて押すと、その文字で始まる次の項目へ動く。空白は検索の途中だけ文字にする
  (それ以外は今までどおり選ぶ・チェックする)。見えている行(TreeView で開いているもの)・選べる項目だけを探す。
- その場での編集: `ItemModel` に `editable(index, column)`(既定は false)と `set_text(index, column, text)` を、`Item` に `editable` を加える。
  - 始め方: F2(current の、編集できる最初の列)、選んでいる current の項目を修飾キー無しでもう一度押す(0.5 秒待ち、ダブルクリックなら始めない)、
    `ItemView::edit(index, column)`。
  - 終わり方: Enter・ほかへのフォーカスの移動・スクロールで確定(文字が変わっていれば `set_text`)、Esc でやめる。モデルの行が変わったらやめる。
  - 編集の欄はビューが 1 つ作って使い回し、編集しないときは隠す。キーはビューへ送らない(↑↓・文字のキーで current が動かないように)。
  - `ListModel`・`TreeModel` の `set_text` は、1 列目なら `text`、2 列目以降なら `column_texts` を変える。

## 影響

- 文字での検索は日本語の文字では探せない(IME を使わないため)。
- 行の背景の色を項目ごとに変えること・編集の欄を ComboBox などにすることは対象外(必要になったら追加する)。
