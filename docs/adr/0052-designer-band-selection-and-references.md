# 0052. デザイナーで範囲で囲んで選び、選んだものをまとめて並べ替え、参照のプロパティを編集し、はみ出した部品を示す

- 状態: 承認
- 日付: 2026-10-12

## 背景

デザイナーの複数選択(Ctrl・Shift+クリック)では、多くの部品を選ぶのに手間がかかった。Alt+↑・↓ は主に選んでいる 1 つしか動かさず、
動かした後は同じ位置の(隣の)ノードを選んでいた。Label の `buddy`(ニーモニックで移る先。docs/adr/0049)のような、ほかの部品を指す
プロパティは編集できなかった。自由な配置で入れ物の外に置いた部品は、外の部分が描かれず、なぜ見えないのか分からなかった。

## 検討した選択肢

- 囲んで選ぶもの: 四角に収まるもの / 四角に掛かるもの。入れ子のどの段を選ぶか: すべての段 / 囲み始めた所の入れ物の直接の部品。
- 部品の上からのドラッグ: 部品を移す(今まで通り)/ 囲む。囲む操作の開き方: 空いた所からだけ / 修飾キーで部品の上からも。
- 参照の編集: 名前の文字の入力 / 型の合うノードの選択肢。
- はみ出しの示し方: 問題パネルの警告(検証)/ キャンバスと構造の木の印。

## 決定

- **範囲で囲んで選ぶ**: 空いた所・レイアウトの上からドラッグすると、いちばん近い入れ物(部品かウィンドウ)の直接の部品のうち、
  四角に掛かるものを選ぶ(VS の WinForms と同じく掛かれば選ぶ。入れ子の段を混ぜない)。部品の上からのドラッグは今まで通り移す。
  Ctrl・Shift を押せば部品の上からも囲み始め(中に部品を入れた部品ならその中を、ほかはその部品の入れ物の中)、今の選択に足す。
  4px 動かすまでは囲まない(クリックは今まで通り)。囲んでいる間も選ぶものを見せる。
- **まとめて並べ替える**: 新しいコマンド `moveSiblings` で、選んでいるものをそれぞれの並びの中で 1 つずつ動かす。端に着いたものと、
  それに続く選んだものは動かさない(テキストエディタの複数行の移動と同じ)。入れ物とその中のものを一緒に選んでもよい(深い並びから動かす)。
  動かした後の位置は写しで同じ処理をして求め、その id で選び直す(名前の無いメニューの項目等もあるので、名前では選び直さない)。
  右クリックの「上へ」「下へ」も同じ。
- **参照のプロパティ**: カタログの `{ ref: クラス }` の型は、同じファイルの型の合う名前を持つノードの選択肢で編集する。
  Label の `buddy` を設定できるプロパティにする(キャンバスでも設定する)。参照する部品を消すと参照も消し、改名すると書き換え、
  一緒に貼り付けると写しを指すようにする。生成するコードでは、部品をすべて作った後に設定する(今まで通り)。
- **はみ出した部品**: キャンバスの描画の結果の位置で、入れ物(部品・ウィンドウ)からはみ出した部品を求め、本来の位置を警告の色の点線で
  示し、構造の木の行に ⚠ とツールチップを出す。位置は描いてみないと分からず、レイアウトの中では起きないので、検証の警告にはしない。
  中身が大きいのが普通の ScrollArea の中は対象にしない。

## 影響

- 範囲で囲む・はみ出しの判定は [canvasGeometry.ts](../../designer/packages/webview/src/canvasGeometry.ts) に分け、実際のキャンバスの描画の
  結果でテストする。
- 見本(designer/samples/main_window)のラベルにニーモニックと `buddy` を加えた。
- 範囲で囲んでいる途中で Esc で取り消す操作、参照の先をキャンバスで線で示す表示は対象外。
