# 0050. 表 TableView は ItemView の表の扱いとして作り、セルの矩形を選んで表計算の流儀で編集する

- 状態: 承認
- 日付: 2026-10-11

## 背景

一覧(ListView)は列を持てるが、選ぶのも編集を始めるのも行の単位で([ADR 0026](0026-item-model-and-views.md)・
[ADR 0046](0046-item-view-text-style-search-and-editing.md))、表(セルを選び、キーでセルの間を動いて値を書き換える)としては使えない。
ADR 0026 では、セル単位の選択を対象外としていた。

## 検討した選択肢

- 作り方
  - 選択肢A: ItemView とは別の部品として、スクロール・見出し・描画を作り直す。
  - 選択肢B: ItemView に表の扱い(木の扱いと同じく、作るときに決める)を加え、TableView はその表の扱いを公開するだけにする。
    モデル・列・見出し・並べ替え・スクロール・その場での編集をそのまま使える。
- 選ぶ単位: セル 1 つだけ / セルの矩形(複数)。
- 編集: 一覧と同じ(F2・選んだ項目のクリック) / 表計算の流儀(文字を打つと上書き、Enter で下へ)。

## 決定

選択肢B で、セルの矩形を選び、表計算の流儀で編集する。

- `TableView`(`views/table_view.hpp`)はモデルの一番上の行を、列ごとに表示する。モデルは ItemModel のまま(`ListModel` なら
  `text` が 1 列目、`column_texts` が 2 列目以降)。
- 選び方 `selection_behavior`: `CELLS`(既定。セルの矩形)・`ROWS`(一覧と同じ行の選択)。キーで動かすセルは `current`(行)と
  `current_column`。`selected_ranges` は選んでいるセルの範囲(`CellRange`)の並び。`selection_mode` の `SINGLE` はセル 1 つ、`MULTI` は矩形を
  複数(Shift+クリック・Shift+矢印・ドラッグで広げ、Ctrl+クリックで加える)、`NONE` は選ばない。
  `selection`(ItemView)は、選んでいるセルのある行の項目にする。行の数・並びが変わると、範囲は current のセルだけにする
  (行の番号で持つ範囲は、行が変わると意味を失うため)。
- キー: 矢印・Ctrl+矢印(端へ)・Home・End・Ctrl+Home・Ctrl+End・Page Up・Page Down。Tab・Shift+Tab は右・左(行をまたぐ。表の端では
  次の部品へフォーカスを移す)。Enter・Shift+Enter は下・上。Ctrl+A ですべてを選ぶ。
- 編集: 編集できるセル(モデルの `editable`)では、文字を打つと上書きで編集を始め(IME の変換を始めたときも、変換中の文字を編集の欄に渡す)、
  F2・ダブルクリックで今の文字の続きから始める。Enter・Tab で確定して下・右へ動き、Esc でやめる。Backspace で空にして始め、
  Delete で選んでいるセルを空にする。編集できないセルのダブルクリックで `on_activate` を呼ぶ。
- クリップボード: Ctrl+C・Ctrl+X で、選んでいるセルを囲む矩形を写す(行は改行、列はタブ。選んでいないセルは空、セルの中のタブ・改行は空白)。
  Ctrl+V で貼る: 1 つの値なら選んでいるすべてのセルへ、表なら current のセル(範囲を選んでいれば、その左上)から貼り、貼った範囲を選ぶ。
  編集できないセルは変えない。
- 見た目: `grid_visible`(既定 true)でセルの間に線を引き、`row_header_visible`(既定 true)で左に行の番号を出す。行の見出しを押すと
  行のすべてのセルを選び、左上の隅を押すとすべてを選ぶ。選んだセルは選択の色で塗り、current のセルを枠で示す。
- Tab を部品が使えるよう、`Widget::handles_tab_key` を加える。true の部品(か子孫)にフォーカスがあるときは、Tab を key_down で送り、
  受け取らなかったときだけ次の部品へフォーカスを移す。
- デザイナーでは、一覧・木と同じく `columns` を子に持つ部品としてパレットの「一覧」に出す(`current_column` は設定しない)。

## 影響

- セルごとの編集の可否は、モデルの `editable(index, column)` で決める。`ListModel` では項目ごと(行ごと)なので、列ごとに変えるときは
  モデルを派生する。
- 列の見出しで列を選ぶ、セルの結合、行の高さを行ごとに変える、セルに数値・日付などの専用の編集の欄を出すことは対象外(必要になったら追加する)。
- 範囲の外側の枠(表計算の太い枠)や、選んだ範囲の右下をドラッグして値を広げる操作も対象外。
