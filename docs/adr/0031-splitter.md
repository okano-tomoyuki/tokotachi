# 0031. Splitter は区画をいくつでも並べ、大きさの変化は区画ごとの比率で配り、区画をたためる

- 状態: 承認
- 日付: 2026-10-04

## 背景

左に木・右に一覧のように、区画を並べて境目をドラッグで動かせる入れ物(分割ウィンドウ)を作る。決めること:

- 区画の数。
- Splitter の大きさが変わったときに、増えた・減った大きさをどの区画に配るか。
- 区画を幅 0 までたためるか。

## 検討した選択肢

- 区画の数: いくつでも(選択肢A)/2 つだけ(選択肢B。それ以上は入れ子)。
- 配り方: 区画ごとの伸びの比率(選択肢A。BoxLayout と同じ考え方)/今の割合を保つ(選択肢B。左だけ幅を保つ、ができない)。
- たたむ: たためる(選択肢A)/たためない(選択肢B)。

## 決定

**すべて選択肢A を選ぶ。** 横・縦の両方に並べられる(`orientation`)。入れ子にもできる。

- 区画は TabWidget の Tab と同じく、Splitter が作って所有する `SplitterPane`(`stretch`・`collapsible`・読み取り専用の
  `collapsed`・`widget`)で表す。`add_widget(widget, stretch)`・`insert_widget` で加え、部品は Splitter の子になる。
  部品を破棄する・別の親へ移すと、その区画は消える。
- 各区画の大きさは `sizes`(並ぶ向きの dp。たたんだ区画は 0)で読み書きでき、保存・復元に使える。代入した値の合計が
  Splitter の大きさと合わない分は、stretch の比率で合わせる。初めは各区画の望む大きさから始め、余りを配る。
- 大きさが変わったときは、たたんでいない区画に stretch の比率で配る(stretch 0 の区画は大きさを保つ。すべて 0 なら最後の区画)。
  縮めるときは各区画の最小の大きさで止め、残りを他の区画へ回す。すべて最小になったら、それより小さくする(はみ出しを切る)。
- 境目(6dp)のドラッグは、両隣の 2 つの区画だけを変える。最小より小さくはならず、collapsible(既定 true)な区画は最小の半分より
  小さくするとたたむ。たたんだ区画は隠し(部品の visible を false にする)、境目をドラッグして戻す。
- 「たたんでいる」は大きさとは別の状態として持つ(望む大きさが 0 の区画を、たたんでいると取り違えないため)。
- ドラッグ中はその場で大きさが変わり、`on_change` を呼ぶ。境目にポインタを乗せると、カーソルを ↔・↕ にする。

## 影響

- 境目のダブルクリックでたたむ・開く、キーボードでの境目の操作は対象外(必要になったら追加する)。
- たたんだ区画の部品の visible は Splitter が決めるので、利用者は区画の部品の visible を変えない。
