# 0045. Font に太字・斜体を加え、OS の書体のファイルを使い、無ければ合成する

- 状態: 承認
- 日付: 2026-10-11

## 背景

`Font` は大きさだけで、太字・斜体が無かった。見出しを太くする、一覧の項目の一部を強調するといった、よくある使い方ができない。
フォントは OS のファイルを使う([ADR 0007](0007-text-stack.md))。Windows は既知のファイル、Linux は fontconfig で探し、
WebAssembly(デザイナーのキャンバス)は拡張が渡すファイルの一覧を使う。

## 検討した選択肢

- 選択肢A: 太字・斜体の書体のファイルを探して使い、無ければ標準の書体を太らせる・傾ける(合成)。
- 選択肢B: すべて合成する。実装は簡単だが、太字の形が本物より弱く、欧文の斜体(イタリック)の字形にならない。

## 決定

**選択肢A。** `Font` に `bool bold`・`bool italic` を加える(`Font(18, true)`)。

- フォールバックの順の一覧を、標準・太字・斜体・太字の斜体の 4 つ持つ。
  - Windows・WebAssembly: 標準の書体のファイルと同じフォルダにある、対応するファイルを使う(Segoe UI → segoeuib・segoeuii・segoeuiz、
    游ゴシック → YuGothB、メイリオ → meiryob、Malgun Gothic → malgunbd、Microsoft YaHei → msyhbd)。無ければ合成する。
    太字の斜体のファイルが無ければ、太字のファイルを傾ける。WebAssembly もネイティブと同じファイルを選ぶので、キャンバスは生成したコードと同じに描く。
  - Linux: fontconfig に `weight=bold`・`slant=italic` を付けて問い合わせ、当たった書体が太字・斜体でなければ合成する。
- 合成: 太字は FreeType の `FT_GlyphSlot_Embolden`(大きさの 1/24 太らせる)と、HarfBuzz の `hb_font_set_synthetic_bold`
  (字の送りも同じだけ広げる)。斜体は `FT_Set_Transform` で 0.2 傾ける(字の送りは変えない)。
- デザイナー: カタログの値の型 `Font` のメンバに `bold`・`italic` が加わる。インスペクタは大きさの欄と B・I の切り替えで編集し、
  生成するコードは `tokotachi::Font(18, true)` のように後ろの既定値を省いて書く。

## 影響

- 日本語の書体は斜体のファイルを持たないので、傾けて描く(OS・ほかのツールキットと同じ)。
- 行の高さは、その太さ・傾きの主の書体で決まる。太字の書体の行の高さが標準と違うときは、同じ大きさでも高さがわずかに変わることがある。
- 太さを細かく選ぶこと(Light・Semibold 等)・書体の名前を選ぶことは対象外(必要になったら追加する)。
