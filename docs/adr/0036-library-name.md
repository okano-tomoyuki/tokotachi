# 0036. ライブラリの名前を Tokotachi(常立)にする

- 状態: 承認
- 日付: 2026-10-10

## 背景

これまで名前は未定で、名前空間・インクルードのパスを仮に `gui` としていた([ADR 0012](0012-ownership-and-naming.md))。
配布(CMake のパッケージ・システムへのインストール)を考えると、`/usr/include/gui/`・`libgui` のような一般的な名前は他と衝突しやすく、
名前空間・インクルードのパス・ライブラリのファイル名・CMake のパッケージ名がすべて名前に連動するので、配布の仕組みを作る前に決める。

このライブラリの位置づけ: さまざまな層にある GUI の土台のうち、必要最小限のもの(SDL3)だけを使い、高機能な GUI ライブラリを
手軽なライセンス(MIT)で提供する。前作 Bethany が Lazarus(LCL)を包むところから始めたのに対し、より低い層から作り直した。
名前は日本の神話・古事にちなむものにする。

## 検討した選択肢

- Onogoro(淤能碁呂島): 国生みで自ら凝り固まってできた最初の島。土台の上の最初の足場で、前作(地名)と対になる。
- Nuboko(天沼矛)・Hashira(天の御柱)・Sukuna(少名毘古那)・Omoikane(思兼)・Musubi(産霊。同名の SDL を使う C++ の
  フレームワークがある)。
- **Tokotachi(常立)**: 国之常立神(くにのとこたちのかみ)。『日本書紀』で最初に現れる神、『古事記』でも神世七代の最初の神。
  名は「国の床(土台)が立ち現れる」「国が永久に立ち続ける」と解される。

## 決定

**Tokotachi にする。** 土台の上にできたもの(Onogoro)ではなく、土台そのものを表し、最も低い層から作り直したという特徴に重なる。
「常」(永久に立つ)は、長く安定して使えるライブラリでありたいという姿勢にもつながる。簡単に調べた範囲では、同名のソフトウェアは無かった。

| 対象 | 名前 |
|---|---|
| 名前空間 | `tokotachi::`(短い別名は公式には用意しない。必要なら利用者が `namespace tt = tokotachi;` とする) |
| インクルード | `<tokotachi/tokotachi.hpp>`(すべて)・`<tokotachi/widgets.hpp>`(グループ)・`<tokotachi/widgets/button.hpp>` |
| ライブラリ・CMake | `libtokotachi`・ターゲット `tokotachi`・`tokotachi::tokotachi` |
| マクロ・環境変数 | 接頭辞 `TOKOTACHI_`(`TOKOTACHI_PROPERTY_MEMBER`・`TOKOTACHI_TRACE` など) |
| 警告・トレースの出力 | `tokotachi: ...`・`[tokotachi] ...` |

- インクルードガードは、置き場所から作り直した(`TOKOTACHI_WIDGETS_BUTTON_HPP`・`TOKOTACHI_SRC_ACTIONS_MNEMONIC_HPP`)。
- これまでの ADR の中の名前空間・インクルードの例も新しい名前に書き換えた(記録の内容は変えない)。

## 影響

- 一般にはあまり知られていない名前なので、README に由来を書く。
- リポジトリのディレクトリ名は、手元の作業に関わるので変えていない。
