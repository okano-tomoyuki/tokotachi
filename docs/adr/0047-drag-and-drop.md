# 0047. ドラッグ&ドロップはウィンドウの中と、OS からの受け取りに対応し、一覧・木の並べ替えに使う

- 状態: 承認
- 日付: 2026-10-11

## 背景

ドラッグ&ドロップが無く、ファイルをウィンドウに落とす・部品の間で運ぶ・一覧や木の項目を並べ替えることができない。
OS との境界は SDL3([ADR 0001](0001-sdl3-as-platform-layer.md))で、SDL3 は OS からのファイル・文字のドロップ(`SDL_EVENT_DROP_*`)を
知らせるが、アプリから OS へドラッグを始める手段は無い。Wayland では、ボタンを押している間のポインタはそのウィンドウだけに届き、
ほかのウィンドウの上の位置が分からない([ADR 0002](0002-target-platforms-and-wayland-first.md))。

## 検討した選択肢

- 選択肢A: 同じウィンドウの中のドラッグと、OS からのファイル・文字の受け取り。
- 選択肢B: A に加え、同じアプリの別のウィンドウへのドラッグ(Windows・X11 だけ。Wayland では動かない)。
- 選択肢C: A に加え、OS へのドラッグ(SDL3 に手段が無く、OS ごとの実装が要る)。

## 決定

**選択肢A。** 動きがプラットフォームで変わらないことを優先する。

### データと操作

- `DragData`(値): `text`・`files`(UTF-8 のパス)・`formats`(アプリが決める名前 → 文字列)と、`source`(ドラッグを始めたウィジェット。
  OS からなら nullptr)。
- `DropAction`: NONE・COPY・MOVE。ウィンドウの中のドラッグは既定で MOVE、Ctrl を押していれば COPY を受け取る側に提案する。
  OS からのドロップは COPY。
- `DragEvent`: 位置(受け取るウィジェットの座標)・データ・修飾キー・`action`(提案された操作。受け取る側が変えられる)・`accepted`。

### ウィジェット

- 受け取る: `accepts_drops` が true のウィジェットに、`drag_move`(入ったとき・動いたとき)・`drag_leave`・`drop` を送る。
  ポインタの下のウィジェットから親へ向かって、`accepts_drops` のものを探す。受け取らない(`accepted` が false か、action が NONE)と、
  さらに親へ送る。ハンドラ `on_drag_move`・`on_drop` でも受け取れる(既定の仮想関数が呼ぶ)。
- 始める: マウスのボタンを押している間に `start_drag(data, label)` を呼ぶ(ふつうは mouse_move で、少し動いてから)。ボタンを離すまで、
  ウィンドウがポインタの位置に label(と、置けないときの印)を重ねて描く。Esc でやめる。終わったら、始めたウィジェットの `drag_finished(action)`・
  `on_drag_finish` を呼ぶ(MOVE なら、始めた側が元のデータを消す)。
- OS からのドロップ: 重ねている間(`SDL_EVENT_DROP_POSITION`)は、データの中身が分からない(OS によって、落とすまで知らせない)ので、
  `DragData::from_outside()` が true で、`files`・`text` は空のまま `drag_move` を送る。落としたときに中身を入れて `drop` を送る。

### 一覧・木(ItemView)

- `drag_enabled` で、選んでいる項目をドラッグできる(文字は 1 列目を改行でつなぐ)。`drop_enabled` で、項目の間・項目の上(木では子にする)に
  落とせる。落とす位置は線(間)か枠(上)で示し、端に近づけるとスクロールする。
- 同じモデルの項目を落としたら、モデルの `move_rows(indexes, parent, row)` で移す(ListModel・TreeModel が実装する。木では自分の子孫へは移せない)。
  ほかのデータは、モデルの `can_drop(data, parent, row)`・`drop_data(data, action, parent, row)` に渡し(既定は受け取らない)、
  モデルが受け取らなければウィジェットのハンドラ(`on_drag_move`・`on_drop`)に任せる(落とした行は `index_at` で引ける)。
- 選んでいる項目を修飾キー無しで押したときは、複数の選択のままドラッグできるように、選択は離したときに変える。

## 影響

- 別のウィンドウ・ほかのアプリへドラッグすることはできない。
- OS からのドロップで、重ねている間に中身(ファイルか文字か)で受け取るかを決めることはできない(落としたときに分かる)。
- WSLg(WSL の GUI)では、Windows のエクスプローラーから Linux のアプリへのドラッグを WSLg が渡さないので、OS からのドロップは届かない
  (カーソルが禁止の形になる。SDL3 の Wayland の受け取り自体は `text/uri-list`・文字に対応している)。
- 一覧・木の中のドラッグは移すだけ(コピーは対象外)。閉じた項目の上で待って開くことは対象外(必要になったら追加する)。
