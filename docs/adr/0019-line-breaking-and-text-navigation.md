# 0019. テキストのレイアウトは複数行とし、改行・書記素・単語の境界は libunibreak(UAX #14・#29)で求める

- 状態: 承認
- 日付: 2026-10-04

## 背景

[ADR 0007](0007-text-stack.md) では、テキストのレイアウトを 1 行(左から右)に限り、改行は libunibreak を使う予定としていた。
複数行の Label・将来の複数行の入力欄のため、改行と複数行のレイアウトを入れる。あわせて、入力欄の単語単位の操作
(Ctrl+矢印・ダブルクリックでの単語の選択)を入れる。

## 決定

### 依存ライブラリ

- **libunibreak 8.0**(zlib)を依存ライブラリに加える。本家は autotools でしかビルドできないので、[deps/libunibreak/CMakeLists.txt](../../deps/libunibreak/CMakeLists.txt)
  を本家のソースのフォルダに写してビルドする([ADR 0005](0005-build-dependencies-from-source.md))。
  コンパイルするファイルは本家の `src/Makefile.am` の一覧と同じにする(`*data.c` の多くは他の `.c` が `#include` するため。
  最初は全部の `.c` を入れて、二重の定義でリンクに失敗した)。
- 改行(UAX #14)・単語(UAX #29)・書記素(UAX #29)の境界をすべて libunibreak で求める。言語は指定しない(既定の規則)。

### 複数行のレイアウト

- `TextLayout(text, font, scale, wrap_width = 0, alignment = Align::START)`。
  - 改行文字(`\n`・`\r\n`・`\r`)は常に行を分ける。改行文字で終わるテキストは、最後に空の行を持つ。
  - `wrap_width` が正なら、改行してよい位置(UAX #14)で、幅に収まるだけ行に詰める(貪欲法)。行末の空白は幅に含めない。
    1 つの単語が幅に収まらなければ、書記素の境界で分ける。日本語の禁則(行の始めに「、」「。」を置かない等)は UAX #14 の規則で満たす。
  - 行を決めた後、**行ごとにシェーピングし直す**(行をまたいだカーニング・合字が残らないように)。
  - `alignment` は各行の横のそろえ方(最も広い行の幅に対して)。
- 行の送りは、主のフォントの `ascent + descent + 行間`(FreeType の height から求める)。全体の高さは `(行数 - 1) × 行の送り + ascent + descent`
  とし、1 行のときの高さはこれまでと変えない。
- API: 1 行専用の `x_for_offset`・`offset_for_x` をやめ、複数行に通用する `caret_position(offset)`(キャレットの左上)・
  `offset_at(Point)` と、行の問い合わせ(`line_count`・`line_of`・`line_start`・`line_end`・`line_rect`・`line_height`)に置き換えた。
  - 折り返した行の境目の位置は次の行に、改行文字の直前の位置はその行に属するとする。
- 描画(`Canvas::draw_text`)は行ごとに描き、クリップの外の行は飛ばす。

### キャレットの位置と単語

- **キャレットを置ける位置は書記素の境界**とする(これまでは HarfBuzz のクラスタの境界)。1 つのクラスタ(合字 ffi など)に複数の書記素が
  あれば、クラスタの幅を等分した位置に置く(合字の途中にもキャレットを置ける)。
- 単語: `next_word_offset`(次の単語の始め)・`previous_word_offset`(単語の始め)は空白を飛ばす。`word_at` は位置を含む単語の範囲。
  UAX #29 の既定の規則では、漢字・ひらがなは 1 文字ずつ、カタカナの連続は 1 つの単語になる(辞書を使った日本語の単語の区切りは対象外)。
- LineEdit: Ctrl+←・→ で単語単位の移動(Shift で選択)、Ctrl+Backspace・Delete で単語単位の削除、ダブルクリックで単語、トリプルクリックで全体を選ぶ。

### Label

- 改行文字で行を分ける。`word_wrap`(既定 false)で幅に合わせて折り返す。
- 折り返す Label は「幅によって高さが変わる」。望む大きさは「幅は折り返さないときの幅、高さは今の幅で折り返したときの高さ」、
  最小の幅は最も長い単語の幅とし、幅が変わったら配置のやり直しを依頼する。1 回の配置の中で 2 回目の計算が走り、落ち着く
  ([ADR 0017](0017-layout.md) の、配置の結果を受けた依頼をまとめて処理する仕組みを使う)。

## 影響

- 段落ごとに、折り返しのために段落全体を 1 回、決めた行ごとにもう 1 回シェーピングする。長い文章で遅ければ、段落全体の結果を再利用する。
- 双方向テキストは未対応のまま(次の段階で SheenBidi を入れる)。
- 言語ごとの改行の規則(日本語の厳格な禁則で小さい「っ」等を行の始めに置かない、など)は、言語を指定する仕組みを作るときに検討する。
