# 0043. デザイナーの部品ファイル: 部品の組み合わせを別の定義ファイルにし、ほかのウィンドウから参照して置く

- 状態: 承認
- 日付: 2026-10-11

## 背景

デザイナー([ADR 0039](0039-designer.md))では、同じ部品の組み合わせ(検索欄とボタン、ラベル付きの入力欄など)を複数のウィンドウで使いたいことがある。
コピー・貼り付けでほかの定義ファイルにも写せるが、写した後は元とつながらないので、直すときはすべての写しを直す必要がある。
C++ のコードでも、同じ組み合わせを関数やクラスにまとめて使い回すのがふつうである。

## 検討した選択肢

- 選択肢A: 部品集(テンプレート)。選んだ組み合わせに名前を付けて保存し、置くと写す。元とはつながらない。
- 選択肢B: 部品ファイル。根が Widget の定義ファイルを作り、ほかのウィンドウから参照して置く。コード生成では `tokotachi::Widget` から派生した
  クラスになり、直すと使っているすべてのウィンドウに効く。

参照の書き方(選択肢B):

- 選択肢B1: `"class"` に部品ファイルのクラスの名前(`"SearchBar"`)を書く。カタログに無いクラスの名前を、どこから探すかを別に決める必要がある。
- 選択肢B2: `"class": "Widget"` と `"component": "parts/search_bar.ttui.json"`(定義ファイルのフォルダからの相対パス)を書く。
  部品ファイルが無い・読めないときも Widget として扱えるので、検証・構造の木・インスペクタはそのまま動く。

## 決定

**選択肢B、書き方は B2。** コピー・貼り付けで A のほとんどは足りるため。

- 部品ファイル: 拡張子は定義ファイルと同じ `.ttui.json`。根(`window`)の `class` を `Widget` にする。メニューバー・ツールバー・ステータスバー・
  Dialog のボタンは書けない。根の `width`・`height` はデザイナーで描く大きさで、生成するコードには書かない(置いた側のレイアウトが決める)。
- 置く側: `{ "name": "panel_search", "class": "Widget", "component": "parts/search_bar.ttui.json", "properties": {...} }`。
  設定できるのは Widget のプロパティ・ハンドラ・`actions` だけ。レイアウト・子は書けない(中身は部品ファイルが決める)。
- 生成するコード:
  - 部品ファイルは `class SearchBar : public tokotachi::Widget`。コンストラクタは `explicit SearchBar(tokotachi::Widget* parent)` で、
    中の部品を作る(ウィンドウと同じく `tokotachi_setup_ui`)。中の部品のメンバ・ハンドラは部品ファイルのクラスのもの。
  - 置く側は `panel_search = new SearchBar(this)` とし、メンバの型は `SearchBar*`。ヘッダで部品ファイルのヘッダを include する。
    中の部品には `panel_search->button_search` で触れる。
  - プロジェクトでは、部品ファイルもプロジェクトのウィンドウの一覧(`windows`)に入れ、同じ規則で出力し、CMakeLists.txt のソースに加える。
- キャンバス([ADR 0040](0040-designer-canvas-ops.md)): 部品ファイルのクラスは WebAssembly の Tokotachi に無いので、置いた部品は Widget として作り、
  部品ファイルの操作の並びを展開して実行する(変数の名前の前に `panel_search.` を付け、`this` を置いた部品にする)。
  順は生成するコードと同じ(部品ファイルの設定が先、置く側の設定が後)。部品ファイルを開いたときは、隠れたウィンドウいっぱいに根の Widget を置いて描く。
- 検証: 部品ファイルの参照の書き方(相対パス・`.ttui.json`)、置く側に書けないもの(レイアウト・子)は core が調べる。
  ファイルが有るか・根が Widget か・参照が循環していないかは、ファイルを読む拡張が調べる(画像と同じ)。

## 影響

- 定義ファイルの書き方が増えた(根の `Widget`・部品の `component`)。今までの定義ファイルはそのまま読める。
- 置いた部品の中身は、置いたウィンドウでは編集できない(部品ファイルを開いて編集する)。中の部品のプロパティを置く側で変えたいときは、
  コードで設定する(部品ファイルのクラスにプロパティを足すことは、[自作部品](../designer/) の課題として別に扱う)。
- 中の部品のハンドラは部品ファイルのクラスに生成する。置く側のウィンドウで受けたいときは、部品ファイルのクラスにコードで足す。
