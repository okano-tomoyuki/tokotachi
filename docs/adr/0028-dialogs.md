# 0028. ダイアログは OS の別のウィンドウとして非同期に開き、ファイルの選択は OS のダイアログを使う

- 状態: 承認
- 日付: 2026-10-04

## 背景

確認・入力のためのモーダルのダイアログと、ファイルの選択を作る。決めること:

- 結果(OK・キャンセルなど)の受け取り方。
- ダイアログを出す場所。
- メッセージのダイアログとファイルの選択を、自前で作るか OS のものを使うか。
- ボタンの並び。

## 検討した選択肢

結果の受け取り方:

- 選択肢A: 非同期だけ。`open()` はすぐに戻り、閉じたときに `on_finish` で結果を受け取る。
- 選択肢B: 同期も用意する(`exec()` がイベントループを入れ子にして、閉じるまで戻らない)。書きやすいが、待っている間に
  ハンドラが親を破棄するなど、入れ子のループに特有の事故が起きる。

出す場所:

- 選択肢A: 親に紐付けた OS の別のウィンドウ(SDL3 の `SDL_SetWindowParent`・`SDL_SetWindowModal`)。
- 選択肢B: 親のウィンドウの中に、背景を暗くして重ねて描く。どの環境でも同じ見た目だが、親より大きくできない。

既製品:

- 選択肢A: メッセージは自前の部品で作り、ファイルの選択は SDL3 を通して OS のダイアログを使う。
- 選択肢B: どちらも OS のもの(`SDL_ShowMessageBox` は同期だけで、テーマとも揃わない)。
- 選択肢C: どちらも自前(ファイルの選択を作る量が多く、最近使った場所・サンドボックスなど OS の機能を使えない)。

ボタンの並び:

- 選択肢A: OS の慣習に合わせる。
- 選択肢B: どの OS でも同じ。

## 決定

**すべて選択肢A を選ぶ。**

### Dialog

- `Dialog(parent, title)` は Window の派生で、親のウィンドウが所有する。中身は普通のウィンドウと同じくレイアウトで並べる。
- `add_button(DialogButton, text)` でボタンを加える。役割は決定(OK・YES・SAVE)・否定(NO・DISCARD)・取り消し(CANCEL・CLOSE)。
  文字を省くと、利用者の言語(SDL_GetPreferredLocales)に合わせた標準の文字にする(今は日本語と英語)。
  決定のボタンは PRIMARY、他は SECONDARY の見た目にする(Button に `style` を加えた)。
- ボタンは下端に右寄せで並べる。**Windows と KDE は「決定 否定 取り消し」、GNOME などは「否定 取り消し 決定」**(XDG_CURRENT_DESKTOP で判断)。
- `open()` は親の中央に置き(Wayland では OS が決める)、大きさを中身に合わせる(幅は 320〜560dp。折り返す文の高さを決めるため、
  幅を決めて配置してから高さを決める)。
- Wayland では、隠れたウィンドウの大きさを変えてから見せると、WSLg で最初の表示が崩れる(枠と中身がずれ、一部が黒くなる)。
  そのため、開くときに大きさを決めてから(OS のウィンドウには触らずに配置して計算する)、大きさが変わるなら
  OS のウィンドウをその大きさで作り直す。
- `finish(result)` で閉じて `on_finish` を呼ぶ。Enter は最初の決定のボタン、Esc・ウィンドウの閉じるボタンは取り消しのボタン
  (ボタンが 1 つだけならそのボタン)。
- **親への入力は、OS のモーダルに加えて、ライブラリでも止める。** 開いている間、親(とその祖先)のウィンドウへのマウス・キー・文字の入力は捨て、
  押されたらダイアログを前に出す(OS がモーダルに対応していない環境、たとえば xdg-dialog の無い Wayland でも止まるように)。
- 単一行の入力欄の Enter は、`on_submit` が無ければ親へ送るようにした(ダイアログの入力欄で Enter を押すと決定になる)。

### MessageDialog

- 印(情報・質問・警告・重大)と、折り返す文。`MessageDialog::show(parent, title, text, buttons, on_finish, type)` は、
  作って開き、閉じたら `on_finish` を呼んでから破棄する。
- 自分のハンドラの中から自分を破棄するため、`Object::delete_later()`(今のイベントの処理の後に破棄する)を加えた。

### FileDialog

- `FileDialog(parent, mode)` に `mode`(OPEN・SAVE・FOLDER)・`title`・`filters`・`location`・`allow_many` を設定して `open()` し、
  `on_finish` で `paths`(取り消したら空)と `selected_filter` を読む。何度でも開ける。
- 開けなかったときは `error` に理由が入る(Linux で xdg-desktop-portal も zenity も無いとき。WSL の既定の環境はこれにあたる)。
- SDL3 の `SDL_ShowFileDialogWithProperties` を使う。コールバックは OS によって別のスレッドで呼ばれるので、結果を写して
  メインスレッドへ送る(`SDL_PushEvent` で送った関数を、イベントの処理の中で呼ぶ仕組みを加えた)。
  待っている間に FileDialog が破棄されたら、結果は捨てる。

## 影響

- 同期の `exec()` は無い。続きの処理はハンドラに書く。
- ボタンの標準の文字は日本語と英語だけ。他の言語は英語になる(翻訳の仕組みは対象外)。
- ファイルの選択の見た目・使える機能は OS による。Linux では xdg-desktop-portal(または zenity・kdialog)が要る。
