# 0020. 双方向テキストは SheenBidi で行の中を見た目の順に並べ、文字の描画は被覆率の補正とサブピクセルの位置決めで品質を上げる

- 状態: 承認
- 日付: 2026-10-04

## 背景

[ADR 0007](0007-text-stack.md) では、双方向テキスト(アラビア語・ヘブライ語)は SheenBidi で扱う予定とし、文字の描画のガンマ補正と
サブピクセルの位置決めは後で決めるとしていた。[ADR 0019](0019-line-breaking-and-text-navigation.md) で複数行のレイアウトを入れたので、
その上に双方向テキストと描画の品質の改善を加える。

## 決定

### 依存ライブラリ

- **SheenBidi 3.0.0**(Apache-2.0)を依存ライブラリに加える。CMake でビルドでき、公開の API は C。内部のビルドに C++14 が要るが、
  依存ライブラリは別にビルドするので [ADR 0003](0003-cpp11.md)(ライブラリ本体は C++11)と矛盾しない。

### 双方向テキスト(UAX #9)

- 段落(改行文字で分かれた範囲)ごとに SheenBidi で埋め込みレベルを求める。段落の基本の向きは、最初の向きの強い文字で決める
  (`SBLevelDefaultLTR`。向きの強い文字が無ければ左から右)。
- 行の範囲は、これまでどおり論理の順で決める(折り返しの判定の幅は、向きによらず論理の順に足した幅)。
- 各行は SheenBidi で見た目の順の連続(run)に並べ、さらにフォントごとの連続に分けてシェーピングする。右から左の連続は HarfBuzz に
  右から左としてシェーピングさせ(グリフが見た目の順で返り、括弧などが鏡像になる)、連続の中のフォントごとの範囲は逆の順に並べる。
- **書記素ごとに見た目の左端・右端と向きを持つ**(`GraphemeBox`)。
  - キャレットは、その位置から始まる文字の先頭の側に置く(左から右の文字なら左端、右から左の文字なら右端)。行の終わりでは、
    最後の文字の末尾の側。いわゆる「強いキャレット」だけを描き、向きの境目の「弱いキャレット」は描かない。
  - クリックの位置からの位置の判定は、書記素の左右の端のうち最も近いものを選び、文字の向きで論理の位置に直す。
  - **矢印キーでの移動は論理の順**(Windows と同じ)。見た目の順の移動は必要になったら加える。
- 選んだ範囲は、双方向の行では見た目で離れた複数の矩形になる。`TextLayout::selection_rects(start, end)` を加え、LineEdit の選択と
  変換中の文字列の下線をこれで描く。
- **`Align::START`・`END` は段落の向きの始め・終わり**とする(右から左の段落では START が右)。TextLayout の行のそろえ方、
  Label の枠の中の位置、LineEdit の中の位置(右から左の段落は入力欄の右端から並べる)に使う。

### 文字の描画の品質

- **被覆率の補正**: グリフの被覆率 c を c^(1/k) に持ち上げてから合成する。sRGB の値をそのまま線形に混ぜると、文字が細く見えるため
  (明るい文字では特に)。k は文字色の明るさで、暗い文字の 1.25 から明るい文字の 1.6 まで変える。環境変数 `TOKOTACHI_TEXT_BOOST` で
  k を固定できる(見え方の確認用。1 で補正なし)。線形の色空間での合成(ガンマを正しく扱う合成)は、描画の層の作り直しが要るので見送った。
- **サブピクセルの位置決め**: グリフの横の位置を 1/4 ピクセル単位で決め、ずらしたビットマップをキャッシュする(キーはグリフの番号と
  ずれの 4 段階)。これまでは位置をピクセルの整数に丸めていたため、文字ごとに最大 0.5 ピクセルずれ、文字の間隔がばらついていた
  (「12dp」の d と p の間が空くなど)。縦はベースラインをピクセルに揃える。LIGHT のヒンティングは縦にだけ効くので、横にずらしても形は崩れない。

## 影響

- Windows(Segoe UI)・Linux(DejaVu Sans 等)とも、アラビア語・ヘブライ語の字形はフォールバックで賄える。アラビア語の文字の連結を
  テストで確かめた(連結した語の幅が、単独の形を並べた幅より狭い)。
- グリフのキャッシュはずれの段階の分(最大 4 倍)大きくなる。
- 縦書き・言語ごとの字形の選び分け(HarfBuzz の language)・絵文字(カラーのグリフ)は対象外のまま。
