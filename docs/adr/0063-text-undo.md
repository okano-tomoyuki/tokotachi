# 0063. 入力欄で元に戻す・やり直す

- 状態: 承認
- 日付: 2026-10-13

## 背景

LineEdit・TextEdit には、元に戻す(Ctrl+Z)が無かった。手引きを書く中で分かった。一般のアプリの入力欄で当然期待される機能なので、
1.0 の前に入れる。

## 検討した選択肢

- 履歴の持ち方: 編集のたびにテキスト全体を写す/変わった部分(位置・消えた文字・入れた文字)だけを持つ。TextEdit では大きな文書も
  扱うので、変わった部分だけを持つ。変わった部分は、編集の前後のテキストの共通の始めと終わりを除いて求める(編集の処理ごとに
  差分を書かずに済み、取りこぼしが無い)。
- まとめ方: 1 文字ずつ戻す/続けて打った文字をまとめる。Qt・Windows の入力欄と同じく、続けて打った文字・続けて消した文字は 1 回で戻す。
- `text` への代入: 履歴に積む/履歴を消す。読み込んだ文書の前の状態(空など)へ戻れるのは不自然なので、Qt の QLineEdit と同じく消す。

## 決定

- TextInputBase(LineEdit・TextEdit の共通の部分)に、`undo()`・`redo()`・`clear_undo_history()` と、読むだけのプロパティ
  `can_undo`・`can_redo`(変わったら知らせる)を加える。
- キー: Ctrl+Z で元に戻す、Ctrl+Y・Ctrl+Shift+Z でやり直す。IME の変換中は何もしない(キーは IME のもの)。
- 履歴に積む編集: 文字の入力(IME の確定を含む)・Backspace・Delete・改行・切り取り・貼り付け・`insert`。キャレットと選択の起点も
  前後で持ち、戻すと編集の前の選択に戻る。
- まとめ方:
  - 続けて打った文字(前の文字の直後に打った)は 1 回で戻す。続けて Backspace・Delete で消した文字も 1 回で戻す。
  - キャレットを動かす・ほかの種類の編集をするとまとまりを切る。
  - 選んだ文字を打った文字・IME の変換中の文字列で置き換えたときは、選択の削除と打った文字を 1 回で戻す。
- 新しい編集をすると、やり直す履歴は消える。`text` への代入は履歴を消す。履歴は 1000 個まで(古いものから捨てる)。

## 影響

- TextInputBase に公開のメンバ(プロパティ 2 つ・関数 3 つ)が増え、ABI が変わる(0.x の間の次の小さい版)。
- 読むだけのプロパティなので、デザイナーのカタログには載らない。
- 入力欄の右クリックのメニュー(元に戻す・切り取り・コピー・貼り付け)は、まだ無い。必要になったら加える。
