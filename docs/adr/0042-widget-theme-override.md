# 0042. ウィジェットごとにテーマの一部を上書きし、子孫に継がせる

- 状態: 承認
- 日付: 2026-10-11

## 背景

[ADR 0023](0023-theme-and-dark-mode.md) では、テーマはアプリケーションが 1 つ持ち、ウィンドウ・ウィジェットごとのテーマ(継承)は対象外とした。
部分的に色を変える手段は色のプロパティ(`Label::color`・`Window::background`)だけで、ボタン・入力欄などの強調の色・地の色は変えられない。

デザイナーでテーマを扱うにあたり(プロジェクトのテーマと、部品ごとの上書き)、「危険な操作のまとまりだけ強調の色を赤にする」
「ある画面だけ角を丸くしない」のように、範囲を限ってテーマを変えたいことが分かった。

## 検討した選択肢

上書きの形:

- 選択肢A: ウィジェットに完全な `Theme` を設定する。一部だけ変えたいときも全体を写す必要があり、入れ子にすると親の上書きが失われる。
  ライト・ダークの切り替えにも、ライト用・ダーク用の 2 つが要る。
- 選択肢B: 上書きする役割・寸法だけを持つ値(`ThemeOverride`)を設定し、親から継いだテーマに重ねる。入れ子にすると合わさる。
  色はライト・ダークで同じにも、別々にもできる。

標準のウィジェットへの効かせ方:

- 選択肢A: 標準のウィジェットの色の読み出し(`theme::accent()` 等。22 ファイル・110 か所)を、すべてウィジェットのテーマを受け取る形に書き換える。
- 選択肢B: 描く・配置する・イベントを処理する間だけ、「今のテーマ」をそのウィジェットに効いているテーマに切り替える(内部の `ThemeScope`)。
  色の読み出しは書き換えない。`ThemeColor::resolve()` も、その間はウィジェットのテーマで解決する。

## 決定

**上書きの形は選択肢B、効かせ方も選択肢B。**

- `ThemeOverride`(値の型): 役割ごとの色(`set(role, color)`・`set(role, light, dark)`・`unset`)と、寸法(`set_radius`・`set_field_radius`・
  `set_field_padding`。負の値は上書きしない)。設定するメソッドは自分への参照を返すので、1 つの式でつなげて書ける(生成するコードもこの形)。`apply_to(theme)` は、`theme.dark_colors` でライト・ダークのどちらの色を使うかを選んで重ねる。
- `Widget::theme_override`(Property)と、`Widget::theme`(ReadOnlyProperty。アプリケーションのテーマに、根に近い順に祖先と自分の上書きを重ねたもの)。
- 継ぐ元は親。ウィンドウはアプリケーション、ポップアップ(`Popup`。ComboBox の一覧・メニュー)は開いた元のウィジェット(`owner_widget`)。
- 効いているテーマは、使うたびに祖先をたどって求める(キャッシュしない)。上書きが 1 つも無ければアプリケーションのテーマをそのまま使う。
- 「今のテーマ」を切り替える場所: 描く(`paint`)・配置する(`arrange_children`)・望む大きさ・最小の大きさを求める・イベント(マウス・キー・文字入力・
  フォーカス)・`resized`・`theme_changed`。ウィンドウの処理がウィジェットを呼ぶ入口(`detail::WidgetAccess`)で切り替える。
- `theme_override` を変えると、自分と子孫に `theme_changed()` を送り、`theme` の変更を知らせ、配置をやり直して描き直す。
  アプリケーションのテーマが変わったときも、すべてのウィジェットに `theme` の変更を知らせる。

## 影響

- 公開の API が増えた(`ThemeOverride`・`Widget::theme_override`・`Widget::theme`)。既存のコードの動きは変わらない。
- 上の場所の外(利用者のタイマーのハンドラ等)で `ThemeColor::resolve()` を呼ぶと、アプリケーションのテーマで解決する。
  ウィジェットに効いている色が要るときは `widget->theme.get()[role]` を読む。
- 「今のテーマ」の切り替えはメインスレッドだけで行う(ウィジェットはメインスレッドだけで扱う。ADR 0034 の描画のスレッドはテーマを読まない)。
- デザイナーでは、プロジェクトのテーマ(配色と上書き)と、部品ごとの `theme_override` を編集できるようにする(docs/designer/)。
