# spike_m1: マイルストーン1の検証

SDL3 のウィンドウに、plutovg で図形を、FreeType + HarfBuzz で文字を同じバッファに描き、
SDL_Renderer のテクスチャで表示する。LineEdit 相当の入力欄で IME の日本語入力を受け付ける。
ライブラリ本体の設計のための技術検証で、コードはライブラリに引き継がない前提(C++11、`-Wall -Wextra -pedantic` で警告なし)。

## ビルドと実行

ビルドの手順はリポジトリの [README](../../README.md) を参照。依存ライブラリはすべて静的にリンクする。

```bash
./build/spike/m1/spike_m1.exe        # Windows(exe 単体で動く)
~/gui-build/main/spike/m1/spike_m1   # Linux(WSL2 の例)
```

Linux では既定で Wayland を使い、使えなければ X11 にする。X11 で試すときは `SDL_VIDEO_DRIVER=x11` を付ける。

## オプション

| オプション | 内容 |
|---|---|
| `--font <file>` | フォントのファイル(既定: Windows は Yu Gothic などの Fonts フォルダの既知のファイル、Linux は fontconfig の `sans-serif:lang=ja`) |
| `--screenshot <file.png>` | 1フレーム描いて PNG に保存して終了する |

## 確認すること

上部の2行に、ビデオドライバ・レンダラ・display scale・pixel density・ウィンドウ/ピクセルの大きさ・前回の描画時間を出している。

1. **起動**: Linux で `video: wayland` になっている。
2. **描画**: 文字(日本語、`AVA To Ty` のカーニング、`ffi fl` の合字)、角丸・グラデーション・曲線が滑らか。
3. **ボタン**: ホバーと押下で色が変わり、ボタンの上で離したときだけ回数が増える。
4. **IME**: 入力欄をクリックしてフォーカスし、日本語を入力する。
   - 変換中の文字列が入力欄の中に下線付きで出て、変換対象の文節は太い下線になる。
   - 候補窓がキャレットの近くに出る。
   - 確定すると文字列に加わる。Backspace / Ctrl+C / Ctrl+V / Esc(フォーカスを外す)。
   - 入力欄の幅を超えると、キャレットが見えるように左にスクロールする。
5. **分数スケーリング**: 125%・150% などで、文字・図形がぼやけずに大きくなり、ボタンのホバーの範囲と候補窓の位置がずれない。
   実行中にスケールを変えたり、スケールの違うモニタへウィンドウを移したりしても追従する。
6. **リサイズ**: Windows でウィンドウの枠をドラッグしている間も描画が追従する(真っ黒や引き伸ばしにならない)。
7. **性能**: `last frame` の値。大きいウィンドウ(4K で最大化など)や arm64 の機器での CPU 描画の時間の目安にする。

## 分かっている制限(検証の範囲外)

- キャレットは常に末尾で、点滅しない。文字の選択・矢印キーの移動は無い。
- フォントのフォールバックが無い(絵文字など、フォントに無い文字は表示されない)。
- 毎回ウィンドウ全体を描き直す(無効化領域の管理はライブラリ本体で行う)。
- 文字の合成はガンマ補正をしていないので、DirectWrite などの OS の描画より細く見えることがある。
