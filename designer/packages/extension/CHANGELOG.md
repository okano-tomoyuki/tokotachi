# Changelog

## 0.1.0 (preview)

The first preview.

- Design windows, dialogs and component files on a canvas drawn by Tokotachi (WebAssembly).
- Palette, structure tree, inspector, layouts (box, grid, free placement), alignment tools, rubber band selection,
  copy and paste, menus, toolbars and actions.
- Built-in icons (Lucide), images, colors, fonts, dates, theme overrides and variable bindings in the inspector.
- C++ code generation with marker regions and handler stubs; projects generate `main.cpp` and `CMakeLists.txt`.
- English and Japanese user interface.
